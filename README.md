# Una Vida de Mánager · V9.79

## Motor continuo · 540 fases y mayor volumen ofensivo

- El partido reglamentario pasa de 360 a **540 fases**.
- Cada fase representa **10 segundos**: 6 fases por minuto y 90 minutos exactos.
- El motor continuo sigue siendo persistente: posesión, portador, ubicación y transición nacen de la fase anterior.
- Se incrementa la intención de pase profundo, centro, remate y regate ofensivo para producir aproximadamente el doble de ataques respecto de V9.78.
- La conversión por remate se compensa para que el aumento de ataques no duplique automáticamente los goles.
- La probabilidad de falta se normaliza por duración de fase para sostener el volumen previo de amarillas y rojas.
- La ventana de contraataque pasa a 11 fases de 10 s, prácticamente igual en tiempo real a las 7 fases de 15 s anteriores.
- Cansancio, lesiones, expulsiones, ventaja local, penalización de marcadores altos y demás subsistemas previos se conservan.
- No hay cambios en Worker, API ni D1.
